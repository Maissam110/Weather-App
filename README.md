 Weather-App

A modern and user-friendly **Weather App built with Flutter** that provides real-time weather information for different locations.
 ✨ Features
* 🌡️ Real-time temperature and weather conditions
* 📍 Search weather by city/location
* 🌅 Sunrise and sunset information
* 💨 Wind speed and other weather details
* 📅 Weather forecast information
* 🎨 Clean and responsive Flutter UI
* ☁️ Weather icons and animations
* 🔄 API-based live weather data
 🛠️ Technologies Used
* **Flutter**
* **Dart**
* **Weather API**
* **REST API**
* **Lottie Animations**
* **Intl Package**
 📱 About the Project
This project was created to practice Flutter development, API integration, asynchronous programming, JSON data handling, and building responsive user interfaces.
Feel free to explore the code, ⭐ star the repository, and contribute to the project!
